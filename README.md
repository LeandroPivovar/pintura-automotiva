# Pintura Automotiva

Site institucional de pintura automotiva em Manaus - AM. HTML/CSS/JS estático, sem build. Tema escuro em
preto e vermelho, com os traços vermelhos do flyer. Base derivada do site da Mecânica JR; as regras próprias
ficam no fim do `styles.css`.

```bash
npx --yes serve . -l 5542
```

## Confirmar com o cliente

- **Nome comercial:** o flyer só diz "Pintura Automotiva". Se for "Elton Pintura Automotiva" ou outro nome,
  trocar na marca, título, rodapé e JSON-LD.
- **Endereço e horário:** não informados. Com o endereço dá para incluir mapa e "Como chegar".
- **Fotos reais:** as imagens são do Unsplash (licença livre). Trocar por fotos de serviços do cliente
  (antes e depois rende muito bem).
- **Logo:** não há arquivo; a marca é texto + ícone.
- **Textos de processo e FAQ** (orçamento por foto, etapas da pintura) são descrições genéricas do serviço;
  validar com o cliente.
